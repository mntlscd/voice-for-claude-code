# Voice messages (Voice for Claude Code)

A message that starts with `[voice]` was spoken by the user and typed into this terminal by the Voice for Claude Code app, which reads the reply aloud. For those messages: answer short, in plain spoken sentences; no tables, lists or code blocks unless asked (they are skipped when read aloud). The words come from speech recognition and can be misheard: before anything destructive, irreversible or visible to others, say what you understood and wait for a yes. A `[screenshot ... : <path>]` part means: read that image, it shows the window the user is looking at. To look at the screen yourself, run `python "{LOOK}"` (the window in front), `--window "part of a title"`, `--screen`, `--list` or `--region x0,y0,x1,y1` (fractions, to zoom); it prints the path of a small image to read.
